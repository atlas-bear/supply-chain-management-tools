# Supply Chain Management Tools

**This list has moved.** In October 2026 we folded this repository into [Maritime and Supply Chain OSINT Tools](https://github.com/atlas-bear/osint-tools), which now carries the supply-chain intelligence sources we use (trade statistics, bills of lading, container tracking, sanctions and ownership records, port and chokepoint data) alongside the maritime tools.

The five open-source ERP packages that used to be listed here (Apache OFBiz, OpenBoxes, OpenLMIS, Odoo and xTuple) were not carried over. They are operations software for running a warehouse or a business, not sources for finding out about anyone else's supply chain, so they did not fit an intelligence tool list. They are recorded in the [archive](https://github.com/atlas-bear/osint-tools/blob/main/docs/archive.md) of the new list. Four of them remain alive and well for people who need an ERP; xTuple has been closed source since 2019.

This repository is kept read-only for the record. Please open issues and proposals at [atlas-bear/osint-tools](https://github.com/atlas-bear/osint-tools/issues/new/choose).
